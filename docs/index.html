Spacepeek

Select a file in Explorer, press Space.

Early pre-release software. Not a signed proper release. It has not been run on a Windows desktop.

Download nightly pre-release

Unsigned builds. Windows 11, x64 and ARM64. A nightly is an untested preview, not a release.

What ships today

  • Text A bounded preview in a monospace font. The window does not take focus from Explorer.
  • Pictures PNG, JPEG, BMP, GIF (first frame), ICO, and WebP. An animated WebP shows the first frame only.
  • Zoom and pan The mouse wheel and + / − zoom a picture, including the numeric keypad. Drag to pan when it is zoomed. 0 fits the picture to the window. 1 shows it at actual size. Arrow keys still change the file.
  • Follows the selection While the preview is open, it follows the file selected in that Explorer window: the arrow keys, or a click on another file.
  • Keyboard Space opens the preview. Space or Esc closes it, and so does the × on the header.

Before you run a nightly

The builds are unsigned. On Windows, SmartScreen may warn. Choose More info → Run anyway. Smart App Control may block unsigned apps.

Verify the download against SHA256SUMS on the release page.

Supported system

Windows 11, x64 and ARM64. There is no build for older Windows.
